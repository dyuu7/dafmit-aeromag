# 公开文件核验

这次核验为 0.4 接口调整提供依据。核验范围包括固定的 Zenodo v3 发布记录、两个批次的 readme 压缩包和数据说明书，以及 Flt1004（2020）、Flt2005（2021）两个真实 HDF5 文件。下面的样本级结论仅针对**这两个文件**，不表示已经逐一检查全部 16 个数据文件。

## 上游发布说明表达了什么

[v3 记录](https://zenodo.org/records/12723700) 列出 16 个 HDF5 文件，名称均为 `Flt*_train.h5`，没有单独的 test/holdout HDF5 文件。解析两个批次附带的 readme 压缩包，可得到 175 个文档段落，其中 19 个标为 holdout。这是文档段落数，不是可用样本数。

[2020 数据说明书](https://zenodo.org/records/12723700/files/datasheet_sgl_2020_train.pdf?download=1) 说明公开数据是按时间划分后选出的子集。[2021 数据说明书](https://zenodo.org/records/12723700/files/datasheet_sgl_2021_train.pdf?download=1) 第 2 页明确指出，Flt2005、Flt2017 只包含起飞和转场部分，后续部分保留用于测试。其航次表记录 Flt2005 为 6361 个样本。

因此，train/holdout 确实来自上游的发布与评估设计。公开文件本身仍是多通道时序数据。Holdout 不表示质量差或可丢弃；保留文档标记也不能让尚未发布的样本变得可读。

## 校验通过的文件及实际内容

文件大小和 MD5 校验和与固定发布清单一致。此处的“样本字段”指与 `tt` 长度相同的一维数据集，不包括标量 `N`、`dt`、`info`。

| 文件 | 字节数 | MD5 | 样本数 | 实际样本字段数 | 实际 `tt` 范围 |
| --- | ---: | --- | ---: | ---: | --- |
| `Flt1004_train.h5` | 62722064 | `a17c1678407c02f260d7250b4e6c3a15` | 81408 | 96 | 44370.0–56891.0 |
| `Flt2005_train.h5` | 3235396 | `762e902bb3363508d5b947b7f4910eed` | 6361 | 61 | 54616.0–55252.0 |

两个文件均声明 `dt=0.1`。它们都没有 `split` 数据集，也没有标明训练/holdout 角色的 HDF5 属性。2020 字段说明包含 99 个名称，Flt1004 缺少 `year`、`doy`、`mag_6_uc`。标准化读取会根据日期补齐前两者；缺失的磁测量只有在调用者显式启用缺失字段填充时才会产生空值列。

## 缺失段落与边界误判

Flt1004 没有文档标为 holdout 的 `4014.00`、`4013.00` 航线。它们的文档时间范围分别是 52982.8–53588.29、53774.43–54375.97 秒，其中没有实际样本。真实 `tt` 从 52862.1 直接跳到 54518.2。文件也有其他时间缺口，不能把每个缺口都解释为 holdout。

Flt2005 的 6361 个样本全部属于起飞/转场航线 `2004.00`。最后一个样本的 `tt=55252.0`、`line=2004.00`、`mag_1_uc=53683.432`。文档下一段是 holdout 航线 `2004.01`，恰好从 55252.0 开始。但文件既没有这条航线的样本，也没有文档中后续 holdout 航线的样本。

0.3 版本只依据文档时间区间判断 holdout，把最后一个转场样本误判了：

| 读取方式 | Flt1004 行数 | Flt2005 行数 |
| --- | ---: | ---: |
| 0.3 `split="all"` | 81408 | 6361 |
| 0.3 默认 `split="train"` | 81408 | 6360 |
| 0.3 `split="holdout"` | 0（`NoDataError`） | 1 |
| 0.4 `Selection.all(...)` | 81408 | 6361 |

旧接口返回的那一个“holdout 样本”属于边界误判，不构成可用评估集。0.4 中显式指定 `tt=slice(54616, 55252)` 仍返回 6360 行，这是正确执行调用者要求的左闭右开区间。按航线 `"2004.00"` 读取则返回完整 6361 行。

## 复现核验

`tests/test_integration.py` 使用 h5py 对照完整文件的样本数和测量值，同时检查边界样本、文档存在但文件缺失的航线、2020 时间缺口和字段差异，以及真正的日期时间转换。已有本地文件时，可以完全离线运行：

```bash
MAGNAV_INTEGRATION=1 MAGNAV_DATA_DIR=/path/to/flight-files uv run pytest -m integration
```

目录中应包含上述两个原始文件名。不设置 `MAGNAV_DATA_DIR` 时，启用集成测试会下载这两个文件到临时目录，并检查固定的大小及校验和。仓库不提交源数据文件。

实现保留 `is_holdout` 和来源链接作为文档信息，`read()` 只依据明确的航次、航线和时间条件选择真实样本。这也避免把上游某一种评估设计强加给所有后续实验。
